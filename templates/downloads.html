Policy settings & recovery details

Accepted-only seeding

Keep seeding only when the original source videos have a complete accepted import and meet each release's current minimum requirements. The upgrade target does not affect seeding.

Checks run after post-processing, about once a minute. Source files are retained. This policy never resumes stopped jobs and keeps the client's seed limits. BitTorrent can upload pieces during download and before the next check.

Automatic removal requires the stop policy above. Ryokan checks original files before it decides. Temporary access or inspection failures, shared ownership and open file selections stay paused for review. Removal blocks only the exact source hash. Library files, import history and recovery files stay intact.

Recovery details

Quarantine keeps exact files with no automatic expiry. It does not clear source blocks or resume downloads. Administrative restore uses the saved cleanup receipt, refuses existing targets, and keeps the source blocked. The bounded cleanup tool is scripts/source_cleanup.py; use its restore command with the receipt on the server.
